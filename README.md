# Waypoint (pilote)

Petite application de démonstration — une page de connexion et un tableau de bord —
utilisée comme dépôt pilote pour tester la mise en place de Claude Code : revue de
code automatique sur les pull requests, tests et build en CI.

## Démarrer

```bash
npm install
npm run dev
```

Voir `CLAUDE.md` pour les conventions du projet, et `.github/workflows/` pour les
workflows de revue de code et de CI.
